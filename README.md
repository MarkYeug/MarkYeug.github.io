# MarkYeug.github.io
Repo name must be exactly `MarkYeug.github.io`. Push to `main`, then Settings > Pages > Deploy from branch > main / root.
- `/home/` personal page, `/argus/` novel site (Home, Chapters, World).
- New chapter: add one line to `argus/data/chapters.js`. World text: edit `argus/data/world.js`.
- Release schedule (Mon/Fri 8 AM Alaska time) is set at the top of `assets/main.js` (`R` and the `8` in `at(...)`).
